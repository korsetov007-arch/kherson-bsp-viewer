# TFC bridge addon

This is the Steam Workshop-ready addon folder.

Manual install: copy the folder named `tfc_bridge` into `garrysmod/addons/`, restart Garry's Mod, then start TFC.

Publishing instructions: see [../docs/ADDON_PUBLISHING.md](../docs/ADDON_PUBLISHING.md).

The addon contains only client-side Lua. It does not contain the Windows desktop executable.
