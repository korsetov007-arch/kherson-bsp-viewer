# Kherson BSP Viewer

Локальный 3D-просмотрщик Source BSP: откройте `index.html` в современном браузере и выберите `.bsp`-файл. Карта обрабатывается в браузере и не загружается на сервер.

Кликните по поверхности, чтобы увидеть координаты X/Y/Z в единицах Source. ЛКМ вращает вид, ПКМ перемещает его, колесо мыши меняет масштаб.

Текстуры не отображаются. Для корректного рельефа карта должна содержать стандартные Source displacement-данные.

## Карта

Файлы `.bsp` исключены из Git, так как карты могут быть очень большими. Положите свою карту, например, в `maps/`, а затем откройте её через кнопку **«Открыть BSP»** в просмотрщике.
